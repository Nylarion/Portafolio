# Portafolio

Este es el portafolio que estuve desarrollando para el ramo de **Desarrollo y Diseño Web + IA**. 

## 📝 Objetivo

El objetivo principal del desarrollo de este portafolio fue el aprendizaje de **Bootstrap** como también el uso de la **Inteligencia Artificial** de forma constante para aprender a trabajar con ella. Además, todo su desarrollo fue enfocado en que el portafolio sea de código y muy adaptable, cosa que alguién mas pueda tomarlo y usarlo o modificarlo a su gusto.

---
## 💻 Tecnologías y Herramientas

En este espacio se consolidan diversos proyectos que exploran:
* **Desarrollo de Frontend con el uso de CSS + Bootstrap:** Creación de interfaces limpias, en el caso de este portafolio, lo mas minimalistas posibles y dandole este toque caracteristico de Hyprland (Linux).
* **Logica del código:** Uso de JavaScript para manejar efectos visuales y menus, mientras que se usó PHP para el manejo y uso de consultas en base de datos.
* **Inteligencia Artificial:** Uso de IA para apoyar el desarrollo del proyecto. La IA que se usó durante todo el proyecto fue **Gemini**.

---

## 📂 Estructura del Repositorio

* `/acciones`: Contiene el CRUD completo para que cada parte del portafolio, desde hacer cambios en la biografía hasta subir un proyecto o enviar un mensaje, funcione.
* `/assets`: Contiene el apartado y los scripts de la página.
* `/config`: Contiene el archivo de configuración para conectarse a la base de datos.
* `/ScriptSQL`: Contiene el script para la creación de la base de datos, junto a sus tablas y los datos minimos para que el portafolio funcione.
* `/Documentacion_IA`: Contiene la documentación de los promts que se utilizo con **Gemini**.
* `README.md`: Este archivo, que sirve como guía y presentación general del portafolio.

---

## 💾 Objetivos de la Evaluación y de la creación del portafolio

1. **Uso de Framework:** Poder realizar proyectos con el uso del Framework **Bootstrap**.
2. **Uso del enfoque " Mobile First":** Poder desarrollar el portafolio haciendo que en todo momento se adapte a las resoliciones de los celulares.
3. **Uso de GitHub:** Poder subir el proyecto a GitHub y su documentación, además de hacer un archivo readme.md como éste para poder presentar el portafolio como ya se mencionó antes.
